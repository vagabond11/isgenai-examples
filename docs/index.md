## What these examples demonstrate

The repository contains small, dependency-free Node.js examples for reading the evidence returned by isGenAI. The examples are designed for review workflows: they show the result, its basis, and any available saved creation details without turning an AI-use label into a claim about who authored a file.

The examples cover:

- text and code checks;
- image checks for PNG, JPEG, WebP, and AVIF files;
- saved-prompt extraction for supported image metadata; and
- privacy-conscious request handling and error reporting.
