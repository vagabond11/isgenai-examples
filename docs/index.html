What these examples demonstrate

The repository contains small, dependency-free Node.js examples for reading the evidence returned by isGenAI. They are designed for review workflows: they show the result, its basis, and available saved creation details without turning an AI-use label into a claim about who authored a file.

  • text and code checks;
  • image checks for PNG, JPEG, WebP, and AVIF files;
  • saved-prompt extraction for supported image metadata; and
  • privacy-conscious request handling and error reporting.

See the isGenAI examples on GitHub for runnable scripts, fixtures, license, and validation notes.

This page is maintained by Sam / isGenAI for documentation and reproducible examples. It does not contain production credentials or user uploads.
